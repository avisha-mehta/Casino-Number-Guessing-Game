# Casino Number Guessing Game

## Description

Casino Number Guessing Game is a simple C++ console-based game where the player tries to guess a random number generated by the computer. The player can choose different difficulty levels, and the winning prize depends on the selected difficulty.

The game also demonstrates important C++ programming concepts such as classes, functions, user-defined data types, loops, conditionals, and the Standard Template Library (STL).

## Features

- Three difficulty levels: Easy, Medium, and Hard
- Computer generates a random number
- Limited number of attempts for each difficulty
- Different winning prizes based on difficulty
- Shows whether the guess is too high or too low
- Maintains the player's current money
- Option to play multiple rounds
- Simple and easy-to-use console interface

## Difficulty Levels

| Difficulty | Number Range | Attempts | Prize |
|------------|--------------|----------|-------|
| Easy       | 1 - 50       | 10       | $50   |
| Medium     | 1 - 100      | 7        | $100  |
| Hard       | 1 - 500      | 5        | $500  |

## How to Run

1. Save the program as `main.cpp`.
2. Compile the program using a C++ compiler.

```bash
g++ main.cpp -o casino
```

3. Run the program:

```bash
./casino
```

## How to Play

1. Start the game with $100.
2. Select a difficulty level.
3. The computer generates a random number.
4. Enter your guess.
5. The game tells you whether your guess is too high or too low.
6. Guess the correct number within the given attempts to win the prize.
7. Choose another difficulty to play again or select Exit to quit.
